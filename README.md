

🍽️ Forkify - Recipe Search App**  

🚀 **Live Demo:** [Forkify by Ermiyas](https://forkify-ermiyas.netlify.app/)  

Forkify is a modern **recipe search application** that allows users to **search for recipes**, view detailed ingredients, and even **save their favorite recipes** for easy access. Built with **JavaScript, Web APIs, and modern front-end tools**, it delivers a smooth and interactive user experience.  


✨ Features

✅ Search Recipes – Find thousands of recipes using the Forkify API.  
✅ View Ingredients – Get step-by-step ingredients for each recipe.  
✅ Bookmark Favorites – Save your favorite recipes for quick access.  
✅ Responsive Design – Fully optimized for mobile and desktop screens.  
✅ Fast Performance – Built with modern JavaScript tools for efficiency.  
  

🛠️ Technologies Used
- HTML, CSS, JavaScript (ES6+) 
- SCSS (for styling)
- Parcel (module bundler)
- Forkify API (for fetching recipes) 
- Local Storage (for saving bookmarks)  

🚀 Getting Started

1️⃣ Clone the Repository
```bash
git clone https://github.com/your-username/forkify.git
cd forkify
```

2️⃣ Install Dependencies
```bash
npm install
```

3️⃣ Run the App (Development Mode)
```bash
npm start
```

4️⃣ Build for Production**  
```bash
npm run build
```
